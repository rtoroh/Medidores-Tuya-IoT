Configuracion pendiente

Edita config.json en tuya-meter-dashboard\ con tus API keys y luego pulsa Recargar config. Para obtener las keys:

  1. Entra a iot.tuya.com e inicia sesion con la misma cuenta de la app.
  2. Cloud Development → Create Cloud Project. Selecciona el data center Western America (us) y como metodo de desarrollo Smart Home / Smart Life.
  3. En el proyecto: Devices → Link App Account. Escanea el codigo QR con la app Smart Life / Tuya (Ajustes → Vincular cuenta).
  4. Ve a Overview y copia el Access ID / Client ID y Access Secret / Client Secret.
  5. Pegalos en config.json ("apiKey" / "apiSecret") y recarga esta pagina.
